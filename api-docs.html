REST API Examples

All endpoints are public and require no authentication.

Health Check

curl https://anil.diwi.org/japan-realestate/api/health

List All Prefectures

curl https://anil.diwi.org/japan-realestate/api/prefectures

Get Tokyo Municipalities

curl 'https://anil.diwi.org/japan-realestate/api/municipalities?prefecture_code=13'

Search Transactions

curl 'https://anil.diwi.org/japan-realestate/api/transactions?prefecture_code=13&property_types=Apartment&price_max=50000000&limit=10'

MCP (Model Context Protocol) Tools

AI agents can discover and call these tools to analyze real estate data:

Discover Tools

curl https://anil.diwi.org/japan-realestate/mcp/tools

Available Tools

  • search_transactions - Search deals with filters
  • get_price_trends - Historical price time series
  • get_district_prices - Compare neighborhoods
  • get_median_price - Latest statistics
  • list_prefectures - All regions
  • list_municipalities - Cities/wards
  • list_property_types - Available types
  • get_statistics - Database stats

Call a Tool

curl -X POST https://anil.diwi.org/japan-realestate/mcp/call/search_transactions \
  -H "Content-Type: application/json" \
  -d '{
    "prefecture_code": "13",
    "property_types": "Apartment",
    "price_max": 50000000,
    "limit": 5
  }'

Rate Limiting

Fair Usage Policy

100 requests per minute per IP

Every response includes rate limit headers:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 87
X-RateLimit-Reset: 1695206460

When limit exceeded, you'll receive HTTP 429. Wait 1 minute for automatic reset.
